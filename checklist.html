Meccanismo di Sincronizzazione Git: I browser non possono scrivere direttamente sui file locali senza server. Quando spuntate le checkbox, lo stato viene salvato nel localStorage del browser locale. Per sincronizzare le spunte con il repository remoto, cliccate "Esporta file aggiornato per Git Push", sostituite questo index.html nel repository, e fate git add . && git commit -m "update tasks" && git push. In questo modo entrambi vedrete lo stato sincronizzato all'ultimo pull!
